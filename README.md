# 1021 Portfolio 2023

[포트폴리오 바로가기](https://1021xx.github.io/portfolio2023/)

2023년 웹·그래픽 작업을 모은 개인 포트폴리오입니다. UI 디자인과 웹 퍼블리싱 작업, 브라우저에서 직접 써 볼 수 있는 JavaScript 예제를 담았습니다.

- **UI 디자인** · 한국수력원자력 전산 시스템 리뉴얼 기획 및 디자인
- **웹 퍼블리싱** · 개인 웹사이트 제작과 스타벅스·건축 디자인 사이트 클론 코딩
- **코딩 예제** · 날씨, 달력, 할 일 목록을 담은 대시보드 등 JavaScript 실습
- **그래픽 디자인** · 포토샵 합성, 타이포그래피, 3D 아이콘, 글래스 카드 작업

HTML, CSS, JavaScript로 제작하고 GitHub Pages에 배포했습니다.
